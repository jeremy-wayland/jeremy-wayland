# Jeremy Wayland

Co-founder of **[Krv](https://krv.ai)**. Mathematician (PhD, [TUM](https://www.cit.tum.de/en/cit/home/); formerly [AIDOS Lab](https://aidos.group/)).

At Krv I build AI that works on real clinical data: finding the right patients for clinical trials, and proving that models hold up before they touch care. My research background is topology and geometry for machine learning, and that is still how I think about data.

## Projects

**At Krv**
- **[Pasteur](https://github.com/Krv-Labs/pasteur)**: open-source stress tests for clinical AI, run before a model reaches patients.
- **[Topos](https://github.com/Krv-Labs/topos)**: structural code-quality metrics for agent-written programs.
- **[Pulsar](https://github.com/Krv-Labs/pulsar)**: fast multiverse data exploration in Rust, based on [Thema](https://github.com/Krv-Labs/Thema) (Nature Energy 2025).
- **[Phil](https://github.com/Krv-Labs/phil)**: multiverse imputation for tabular data.
- **[Trailed](https://github.com/Krv-Labs/trailed)**: topological regularization for EHR models.

**Research**
- **[Rings](https://github.com/aidos-lab/rings)**: how much graph structure and node features each contribute (ICML 2025).
- **[SCOTT](https://github.com/aidos-lab/curvature-filtrations)**: curvature filtrations for comparing graph distributions (NeurIPS 2023).
